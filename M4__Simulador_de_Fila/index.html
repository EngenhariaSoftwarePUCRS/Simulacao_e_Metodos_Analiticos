Explicação do Simulador de Fila

Este módulo implementa uma simulação de eventos discretos para uma fila G/G/c/K. As chegadas e os tempos de serviço são amostrados de distribuições uniformes, com base em um gerador congruencial linear (LCG) único e sequencial.

Cada evento possui estrutura { tempo, tipo }, onde tipo pode ser CHEGADA ou SAÍDA. A lista de eventos é mantida ordenada por tempo, e o próximo evento processado é sempre o de menor tempo.

X(n+1) = (a * X(n) + c) mod M, com U = X / M

Antes de processar cada evento, o simulador calcula o intervalo de tempo desde o evento anterior e acumula esse intervalo no estado anterior do sistema. O estado i representa o número total de clientes no sistema (fila + serviço).

Ao final, são calculadas as probabilidades de estado P(i) = tempo(i) / tempoTotal, a população média Nmedio, a probabilidade de sistema vazio P(0) e o total de perdas por bloqueio quando N atinge K.
